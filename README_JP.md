# UMDoc -> Markdown

> **言語**: [简体中文](README.md) | [English](README_EN.md) | 日本語

WindowsとmacOSの両方で動作するモダンなデスクトップツールです。ほぼすべての一般的なドキュメントを、ワンクリックでクリーンなMarkdownテキストに変換します。
マイクロソフトがオープンソースで公開しているMarkItDownエンジンをベースに、[all] の全依存関係をインストールしており、Office、PDF、画像、音声、電子書籍など30以上のファイル形式に対応しています。

## 特徴

- 万能変換：Word、Excel、PowerPoint、PDF、画像、音声、EPUB、HTML、CSV、JSONなど、さまざまな形式をMarkdownに変換できます。
- ドラッグ＆ドロップで簡単操作：ファイルをウィンドウにドラッグするか、ボタンで選択するだけで、自動的にフォーマットを判別して変換します。
- スマートなExcel対応：ファイルがExcelブックの場合、シート一覧が表示され、変換したいシートだけを選択できます。他の形式ではシート選択エリアが非表示になり、すっきりとした画面を保ちます。
- デュアルビュープレビュー：「ソース」ビューと「レンダリング」ビューを瞬時に切り替えられ、生のMarkdownと整形後の表示を確認できます。
- 柔軟な保存方法：任意の名前でMarkdownファイルとして保存できるほか、「保存先」からフォルダを選ぶだけで、元のファイル名で自動的に `.md` ファイルが生成されます。
- モダンでクリーンなインターフェース：明るいテーマと角丸カードデザインで、快適な操作感を提供します。
- 自動多言語検出：起動時にシステムの言語設定を読み取り、中国語、日本語、Englishを自動選択します。手動での切り替えもメニューからいつでも行えます。
- 自動環境管理：`launcher.py` が必要な依存関係（PySide6、markitdown[all]など）をプロジェクトフォルダ内の独立した仮想環境にインストールします。システムのPython環境を汚しません。

## クイックスタート

### 前提条件

- Python 3.9以上
  macOSの場合：Homebrewでインストールすることを推奨します：`brew install python`
  Windowsの場合：python.org からダウンロードしてください

### インストールと実行

1. リポジトリをクローン
   ```
   git clone git@github.com:PacteraSunChao/umdoc.git
   cd umdoc
   ```

2. ランチャーで実行（推奨）
   ```
   python3 launcher.py
   ```
   初回起動時には、プロジェクトフォルダ内に仮想環境 `app_env` が作成され、必要な依存関係（PySide6、markitdown[all]など）がすべてインストールされます。
   2回目以降はそのままメイン画面が起動します。

3. または手動で依存関係をインストールしてメインプログラムを実行
   ```
   python3 -m venv app_env
   source app_env/bin/activate   # macOS/Linux
   app_env\Scripts\activate      # Windows
   pip install PySide6 "markitdown[all]"
   python3 umdoc.py
   ```

### 使い方

- アプリを起動し、対応ファイル（例：.docx、.pdf、.xlsx、.jpg）をファイルエリアにドラッグ＆ドロップするか、ボタンからファイルを選択します。
- ファイルがExcelブックの場合、シート一覧が表示されるので、変換したいシートを選択し（「すべて選択」「選択解除」対応）、「Markdownに変換」をクリックします。
- その他の形式では、自動的に変換が実行され、プレビューエリアに結果が表示されます。
- 「ソース」と「レンダリング」ボタンで、生のMarkdownと整形されたプレビューを切り替えることができます。
- 「保存先」をクリックしてフォルダを選択すると、元のファイル名で `.md` ファイルが自動生成されます。メニューの「ファイル -> Markdownを保存」から任意の名前と場所で保存することも可能です。

## 対応ファイル形式

`markitdown[all]` の依存関係をインストールすることで、以下の一般的なファイルタイプを処理できます。

| カテゴリ | 形式 |
| :--- | :--- |
| Officeドキュメント | .docx, .pptx, .xlsx, .xls |
| PDF | .pdf |
| 画像 | .jpg, .png など（OCRテキスト抽出対応） |
| 音声 | .wav, .mp3（Azure AI Speechサービスの構成が必要） |
| 電子書籍 | .epub |
| Web & データ | .html, .csv, .json, .xml |
| アーカイブ | .zip（アーカイブ内の認識可能なファイルを自動解凍・変換） |
| メール | .msg（Outlookメッセージ） |
| その他 | YouTubeリンク（Markdownの説明文に変換） |

注：音声の文字起こしやYouTubeリンクの解析などの高度な機能を利用するには、Azure AIまたはLLMクライアント（例：OpenAI）の追加設定が必要です。これらの設定がない場合でも、MarkItDownは利用可能なメタデータを抽出します。

## 技術スタック

- PySide6 - クロスプラットフォームGUIフレームワーク
- MarkItDown - マイクロソフトがオープンソースで提供するドキュメント→Markdown変換エンジン
- openpyxl - Excelファイルの読み取り（シート名の取得に使用）
- その他、`markitdown[all]` によって自動インストールされるPDF、画像処理、HTML解析などのライブラリ

## 多言語対応

本アプリケーションは、中国語、日本語、Englishの3つのインターフェース言語をサポートしています。
起動時にシステムのロケールに基づいて自動選択され、メニューの「言語 / Language / 言語」からいつでも切り替えられます。
